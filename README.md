# CryptoLabX_GroupXX

## Project Overview
CryptoLabX is a modular cryptography learning environment designed to support encryption, decryption, cryptanalysis, and file analysis workflows. This project provides a menu-driven CLI, file statistics analysis, logging, and structured datasets to support future assignments.

## Folder Structure
- `analysis/` - core analysis modules for file and text processing
- `attacks/` - future attack implementations
- `classical/` - classical cipher algorithms
- `datasets/` - sample text files for analysis and future assignments
- `docs/` - documentation and design notes
- `math/` - mathematical utilities and helpers
- `modern/` - modern cryptography frameworks and tools
- `outputs/` - generated outputs, including execution logs
- `tests/` - unit tests and validation scripts
- `utils/` - helper utilities such as logging and configuration
- `main.py` - main CLI entry point
- `README.md` - project description and usage instructions
- `requirements.txt` - Python dependencies

## Current Features
- Menu-driven command line interface with options:
  - Encrypt
  - Decrypt
  - Attack
  - Analyze
  - Exit
- File analysis for dataset text files, including:
  - character count
  - word count
  - line count
  - unique character count
  - letter frequency
- Execution logging for every menu action

## Future Modules
